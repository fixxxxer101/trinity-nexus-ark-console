RCON is disabled on Xbox servers

Nitrado only makes RCON available on PC servers. This service is the Xbox / console kind, so the RCON port is never exposed — the command menu below can't connect here, no matter the password. It stays in the console because the same app works against PC servers, where it unlocks normally.

Locked

Enter this server's RCON password (the server admin password) to unlock the command menu. The password is kept only in the console app's memory while it runs — it is never saved to disk, and Lock or closing the app forgets it.
